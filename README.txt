CIBURUYAN AKUAKULTUR - KALKULATOR PWA

Cara penggunaan:
1. Upload seluruh isi folder ini ke hosting yang menyediakan HTTPS.
2. Pastikan index.html menjadi halaman utama.
3. Bagikan URL HTTPS-nya melalui WhatsApp/Telegram.
4. Di Chrome Android, buka URL tersebut lalu pilih "Pasang Aplikasi" jika tombol muncul,
   atau gunakan menu browser "Tambahkan ke layar utama".

PENTING:
- Jangan hanya mengirim file index.html lewat WhatsApp/Telegram jika ingin mode PWA.
- manifest.webmanifest, sw.js, dan icon.svg harus berada satu folder dengan index.html.
- PWA membutuhkan HTTPS (localhost untuk pengujian lokal adalah pengecualian).
- Kalkulator tetap dapat digunakan offline setelah pernah dibuka dan service worker aktif.
